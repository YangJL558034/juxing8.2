# 全站界面优化清单

> 目标：**一眼看懂、不用猜**。每个页面做到「一个页面一件事、筛选只有一组、状态用色区分、详情点开看」。

## 统一规范（所有页面共用）

| 项 | 规范 |
|---|---|
| 页面骨架 | 标题栏（图标+标题+说明）/ 唯一筛选行 / 状态页签（带数字）/ 表格 / 详情抽屉 |
| 表格列 | 最多 6 列；次要信息（身份证、手机号、提交时间）进详情 |
| 状态色 | 待审核=橙、已通过=绿、已驳回=红、已删除=灰 |
| 操作 | 主操作外露（审核/办理），其余收进 `⋯` |
| 空状态 | 图标 + 一句说明 + 引导按钮 |
| 数字 | 统计数字放页签上，不放大卡片 |

---

## P0 优先级（最乱、最常访问）

### 1. 社保管理
| 现状问题 | 改后效果 |
|---|---|
| 页签之间无提示，用户不知道待审核在另一个标签 | 页签带数字徽标 + 待审核红色圆点 |
| 表格 11 列，身份证/手机号/导出时间挤成一团 | 精简为：员工（含部门）· 参保城市 · 合同期 · 状态 · 操作 |
| 状态列混了「在职 + 已通过」两种信息 | 状态只表示审核结果；在职/离职做成名字后的小标签 |
| 待审核记录和已购买混在同一表格 | 已经拆开（保持），并在页签上标数字 |
| 空政策：不购买/购买/声明三张表概念重叠 | 页签文案改为：购买社保 · 未购买社保 · 待审核 · 声明记录 |

### 2. 劳动合同
| 现状问题 | 改后效果 |
|---|---|
| 三层筛选：在职/离职 → 管理部/车间 → 搜索 | 合并为一行：搜索 + 部门 + 在职状态 |
| 11 列（入职日期、已入职天数、合同状态、期限、到期、续签、倒计时） | 保留：员工 · 合同期限 · 到期时间 · 倒计时 · 状态 · 操作 |
| 超期红色数字与其他信息混排 | 倒计时用胶囊标签：`剩 12 天`（灰）/`超期 30 天`（红） |
| 已离职员工的合同也在主列表 | 已按「在职/已离职」分开（保持），离职列表整列置灰只读 |

### 3. 入职登记
| 现状问题 | 改后效果 |
|---|---|
| 筛选区只有搜索，没有状态筛选 | 加页签：待审核 · 已审核 · 已离职（带数字） |
| 表格行无悬停反馈 | 行 hover 浅蓝 |
| 空状态只有一行灰字 | 图标 + "还没有入职登记，新员工提交后会出现在这里" |
| 详情抽屉字段平铺 20+ 行 | 分 4 组卡片：基本信息 / 联系方式 / 健康信息 / 签名 |
| 审核弹窗混着试用期设置 | 分两段：审核意见（上）· 试用期设置（下，独立浅灰卡片） |

## P1 优先级（结构清楚，但信息密度差）

### 4. 住宿申请
| 现状问题 | 改后效果 |
|---|---|
| 5 张统计大卡片占半屏 | 数字移到页签：待审核 1 · 已入住 12 · 已退宿 8 |
| 表格 9 列（序号、手机号、部门职位、提交时间） | 精简为：员工（含部门）· 宿舍房号 · 入住日期 · 状态 · 操作 |
| 操作按钮平铺 4-5 个 | 主操作外露（审核/入住/退宿），其余进 `⋯` |

### 5. 房号 / 床位 / 水表管理
| 现状问题 | 改后效果 |
|---|---|
| 三张表样式不统一 | 统一表格样式、统一操作按钮位置 |
| 床位占用状态不直观 | 床位做成卡片网格，已住=绿、空床=灰虚线 |

### 6. 转正申请
| 现状问题 | 改后效果 |
|---|---|
| 5 个页签文字过长 | 缩短：试用期 · 待审核 · 已审核 · 已驳回 · 已删除 |
| 试用期员工行内按钮只有一个「转为正式工」 | 加「查看」「提醒员工」 |
| 驳回没在列表体现原因 | 已驳回行显示原因摘要（截断 20 字） |

### 7. 离职申请 / 解除劳动合同
| 现状问题 | 改后效果 |
|---|---|
| 两张表状态叫法不同（待处理/待审核） | 统一为「待审核」 |
| 缺少离职日期、交接状态的直观显示 | 加倒计时标签：`3 天后离职` |
| 导出/打印按钮分散 | 统一收到操作列 |

---

## P2 优先级（细节打磨）

### 8. 工作证明 / 请假申请 / 物品领用 / 账号注销
- 统一表格样式与状态色
- 统一空状态
- 详情抽屉分组

### 9. 用户管理 / 用工管理
- HR 联系方式卡片改成独立「设置」入口，不占列表顶部
- 用户表格加角色色彩标签

### 10. 工资查询
- 月度列表加「已签/未签」筛选页签
- 签名状态用图标 + 文字，不用纯颜色

---

## 实施顺序建议

| 阶段 | 内容 | 预计 |
|---|---|---|
| 第 1 阶段 | 统一规范落地组件（表头、状态标签、空状态、操作菜单） | 1 次 |
| 第 2 阶段 | P0 三页：社保管理、劳动合同、入职登记 | 3 次 |
| 第 3 阶段 | P1 四页：住宿、房号床位、转正、离职 | 4 次 |
| 第 4 阶段 | P2 收尾 | 2 次 |

**每阶段独立验收、独立提交，出问题只回滚该阶段。**
